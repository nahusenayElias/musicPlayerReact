# React Vite Media Player

A simple and customizable media player built with React and Vite. This project demonstrates how to create a video (or audio) player app with playlist support, leveraging the fast development experience of Vite and the component-based architecture of React.

## Features

- Fast setup with Vite
- Modern React (hooks and functional components)
- Play, pause, and seek controls
- Responsive UI
- Easily extensible (add volume, next/previous, etc.)

## Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/nahusenayElias/musicPlayerReact
```

**2. Install dependencies**

```bash
npm install
```
**3. Run server**

```bash
npm run dev
```
